# ouf-vertical-mock

Verticale di prova per ouf: genera a intervalli istanze di oggetti con tutti gli attributi ed espone il contratto `ouf.vertical-source.v1` (collezioni, schema versionato, istanze con delta per cursore, watermark o snapshot, cancellazioni, ritardi, duplicati, cambio di schema comandabile).

Serve a qualificare il profilo di estrazione, lo scheduler dell'Ingestion, il delta di acquisizione e il blocco per cambio di schema con rimando all'Onboarding (D-075, D-076, D-077).
